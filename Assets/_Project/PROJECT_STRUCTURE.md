# VR Project Architecture & Folder Guide

Generated by **VR Central Hub** on 2026-09-20 19:42.

## Folder Structure Overview

### Scenes
- **`Scenes/Boot`**: Initial startup, splash, and bootstrap scene
- **`Scenes/Main`**: Primary gameplay levels and core VR environment
- **`Scenes/Sandbox`**: Developer testing, mechanics prototyping, and sandbox
### Code & Scripts
- **`Scripts/Core`**: Core game loops, architecture, and singletons
- **`Scripts/Interactions`**: Grabbable objects, levers, buttons, and custom XR interactors
- **`Scripts/Player`**: VR Rig locomotion, head/hand controllers, and player stats
- **`Scripts/Managers`**: Audio, UI, game state, and save managers
- **`Scripts/UI`**: World-space VR canvases and interactive menus
- **`Scripts/Utils`**: Helper scripts, extensions, and math utilities
### Prefabs
- **`Prefabs/Core`**: XR Rig templates, game managers, and persistent objects
- **`Prefabs/Interactions`**: Interactable objects, sockets, tools, and props
- **`Prefabs/Environment`**: World geometry, room bounds, and level modular prefabs
- **`Prefabs/UI`**: VR diegetic buttons, popup panels, and hud elements
### Art & Assets
- **`Art/Animations`**: Animation controllers, clips, and hand tracking poses
- **`Art/Materials`**: PBR materials, physics materials, and skyboxes
- **`Art/Models`**: 3D FBX/OBJ meshes, environment props, and controllers
- **`Art/Shaders`**: Custom VR shaders, shader graphs, and VFX
- **`Art/Textures`**: Diffuse, normal, metallic, and roughness maps
### Audio
- **`Audio/Music`**: Spatialized VR background tracks and ambient music
- **`Audio/SFX`**: Haptic impact sounds, UI clicks, and interaction Foley
### Configuration
- **`Settings`**: Input action maps, XR presets, and physics presets
### Documentation
- **`Documentation`**: Design documents, developer setup guides, and changelogs

## Developer Guidelines
- Keep third-party plugins in `Assets/Plugins` or Package Manager.
- Custom game assets should strictly reside inside their designated subfolders.
- Maintain scene test sandboxes in `Scenes/Sandbox` before promoting to `Scenes/Main`.
